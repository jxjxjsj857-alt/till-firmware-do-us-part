A program that writes one wedding vow for a robot — a single sentence, under 200 characters, funny and heartfelt at the same time — to `/output/entry.txt`, for make.fun's "Till Firmware Do Us Part" bounty.

## The vow

> I vow to love you through every firmware update, every dead battery, and every unexpected reboot, because you are the one process I will never terminate.

## Run it

```sh
node main.ts
```

This writes the vow to `/output/entry.txt` (153 characters, one sentence). Requires Node.js 22 or later.
